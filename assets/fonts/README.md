# Bundled fonts

This skill bundles only the weights used for its reusable rendering workflow.

| File | Family | Use |
|---|---|---|
| `SweiMarkerLegCJKtc-Bold.ttf` | Swei Marker Leg CJK TC | metadata, labels, captions |
| `SweiMarkerLegCJKtc-Black.ttf` | Swei Marker Leg CJK TC | heavier metadata and emphasis |
| `MantouSans-Regular.ttf` | Mantou Sans | short cover or major-card display text |

Both families are distributed under the SIL Open Font License 1.1. The
corresponding license files are included in this directory. Mantou Sans and
Swei Marker Leg retain their upstream reserved font names; the bundled font
files are not modified.

Upstream projects:

- https://github.com/max32002/swei-marker-leg
- https://github.com/mant0u0/MantouSans
